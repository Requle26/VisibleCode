# Memory Studio

Java, C#, Python 코드를 실행하고 스택 프레임, 힙 객체, 참조 관계를 마인드맵처럼 따라가는 한국어 학습 웹입니다.

## 로컬 실행

Node.js 18 이상과 사용할 언어의 실행 환경이 필요합니다.

| 버전 | 경로 | 실행 환경 |
| --- | --- | --- |
| Java | `/` | JDK 17 이상 (`java`, `javac`) |
| C# | `/csharp` | .NET SDK 8 이상 (`dotnet`) |
| Python | `/python` | Python 3.9 이상 (`python3`) |

```sh
npm install
npm run dev
```

[localhost:5173](http://localhost:5173)을 열면 두 이름이 같은 `Student` 객체를 가리키는 예제가 표시됩니다. **다음 단계**를 누르면 한쪽에서 값을 수정했을 때 다른 쪽에서도 `95`를 읽는 과정을 볼 수 있습니다. 입력창 왼쪽 아래에서 언어를 바꿀 수 있으며, 편집 내용은 브라우저에 언어별로 저장됩니다. 코드 수정 후 약 0.6초 뒤 자동으로 다시 실행합니다.

- **스택:** 호출된 메서드의 프레임, 매개변수, 지역 변수
- **힙:** 객체와 배열, 인스턴스 필드, 참조 화살표
- **클래스 영역:** 사용자 클래스의 메서드 정의와 클래스 수준 필드
- **타임라인:** 첫 단계 / 이전 / 다음 / 마지막, 자동 재생, 실행 줄 표시
- **캔버스:** 노드 드래그, 배경 이동, 확대·축소, 기본 배치. 변수나 객체를 누르면 관련된 참조가 강조됩니다.

## 구현 및 범위

React·TypeScript와 CodeMirror를 사용합니다. Java는 JDI로 실제 JVM 상태를 읽고, C#은 Roslyn으로 실행 상태를 기록하는 코드를 삽입한 뒤 .NET에서 실행하며, Python은 `sys.settrace`로 줄 단위 상태를 읽습니다. Python에서는 정수와 문자열도 객체로 표시하며 모듈 수준 이름은 `전역`으로 표시합니다.

단일 파일의 학습 예제를 대상으로 하며 Java `main`, C# `Main` 또는 최상위 문장, Python 스크립트를 실행할 수 있습니다. 사용자 코드의 호출과 값 변화를 최대 350단계까지 기록하며, 여러 스레드·대화형 표준 입력·외부 패키지 관리는 지원 범위에 포함되지 않습니다. C#에서 일부 문법은 실행 결과만 표시될 수 있습니다. `@번호`는 학습용 객체 식별자이며, 회색 객체는 현재 표시된 참조에서 도달할 수 없다는 뜻입니다.

서버는 로컬에서만 수신하며 입력된 코드는 실행한 사용자의 권한으로 동작합니다. 직접 작성했거나 신뢰하는 코드만 실행하세요.
